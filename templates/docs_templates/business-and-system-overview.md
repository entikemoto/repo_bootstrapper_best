## 5. 部品の依存関係

### 依存関係マトリクス

どの部品がどの部品に依存しているかを示します。
「✓」がある場合、行の部品は列の部品に依存しています。

|        | ① | ② | ③ | ④ | ⑤ | ⑥ |
|--------|---|---|---|---|---|---|
| **①** | - |   |   |   |   |   |
| **②** |   | - |   |   |   |   |
| **③** |   | ✓ | - |   |   |   |
| **④** |   | ✓ |   | - |   |   |
| **⑤** |   |   | ✓ | ✓ | - |   |
| **⑥** |   |   |   |   |   | - |

### 依存関係図

```
（依存関係を視覚的に図示）

┌─────┐
│ ①   │ 独立（依存なし）
└─────┘

┌─────┐
│ ②   │ 独立（依存なし）
└──┬──┘
   │
   ├─────────┐
   ▼         ▼
┌─────┐   ┌─────┐
│ ③   │   │ ④   │  ②に依存
└──┬──┘   └──┬──┘
   │         │
   └────┬────┘
        ▼
     ┌─────┐
     │ ⑤   │  ③④に依存
     └─────┘
```

### 並行開発の可能性

| グループ | 部品 | 備考 |
|----------|------|------|
| **独立して開発可能** | ①, ② | 他に依存しないため、最初に着手可能 |
| **②完了後に開発可能** | ③, ④ | ②のみに依存するため並行開発可能 |
| **③④完了後に開発可能** | ⑤ | ③④両方が必要 |

## 7. 開発の順番

依存関係を考慮した開発順序です。

| 順番 | 作る部品 | 依存先 | 並行開発 | 理由 |
|------|----------|--------|----------|------|
| **1** | ○○○○ | なし | - | 独立しており、土台となる |
| **1** | ○○○○ | なし | ↑と並行可 | 独立しており、並行開発可能 |
| **2** | ○○○○ | ②に依存 | - | ②完了後に着手 |
| **3** | ○○○○ | ③④に依存 | - | ③④完了後に着手 |
